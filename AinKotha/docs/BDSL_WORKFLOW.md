# AinKotha BdSL (বাংলা সাইন ল্যাংগুয়েজ) ওয়ার্কফ্লো

লক্ষ্য: বধির/শ্রবণপ্রতিবন্ধী ব্যবহারকারীকে সাইন অ্যাভাটার দিয়ে **কেন কল করবেন** আর **কোন নম্বরে কল করবেন** অটো দেখানো।

## ১. পাইপলাইন

```
ব্যবহারকারীর টেক্সট/ভয়েস
        │
        ▼
POST /api/chat  →  { category, services[], is_emergency }     (বিদ্যমান ব্যাকএন্ড)
        │
        ▼
app.js → AinKothaSign.onReply(data, language)
        │
        ▼
sign.js: buildSteps(service)   ← LLM নয়, শুধু যাচাই করা services.json
   [কারণ] → [কল করুন] → [অঙ্ক১] [অঙ্ক২] … → [পুরো নম্বর]
        │
        ├─ স্তর ১ (সবসময়): বড় ভিজ্যুয়াল কার্ড, ~২.৬ সেকেন্ড/ধাপ, auto-advance
        │
        └─ স্তর ২ (ডেটাসেট থাকলে): CWASA অবতার SiGML চালায়, ~৪.৮ সেকেন্ড/সাইন
                 শব্দ ডেটাসেটে না মিললে ঐ ধাপে কার্ড দেখায়
```

জরুরি (`is_emergency`) হলে সেবা হিসেবে সরাসরি ৯৯৯ বসানো হয়।

## ২. ফাইল

| ফাইল | কাজ |
|---|---|
| `frontend/sign.js` | ধাপ তৈরি, ডেটাসেট লোড, CWASA, প্লেব্যাক, `window.AinKothaSign` |
| `frontend/index.html` | `#signBtn` টগল, `#signPanel` (অবতার + কার্ড) |
| `frontend/app.js` | `handleUserTranscript`-এ `onReply` কল; `endCall`-এ বন্ধ |
| `frontend/style.css` | `.sign-*` স্টাইল |
| `frontend/bdsl/` | (আপনি বানাবেন) ডেটাসেট |

## ৩. আপনার বাকি কাজ (চেকলিস্ট)

1. **ডেটাসেট বসান:** IsharaKotha `.sigml` ফাইল `frontend/bdsl/` এর নিচে রাখুন। লাইসেন্স/প্রোভেন্যান্স আগে যাচাই করুন।
2. **`frontend/bdsl/dataset.json` বানান:** অ্যারে, প্রতিটি entry `{gloss, english, sigmlPath, datasetRoot}`। পুরনো ম্যানিফেস্ট স্ক্রিপ্ট `{name, entries}` লেখে, সেটাকে অ্যারেতে বদলান। ফোল্ডারনামের mojibake থাকলে ফাইল রিনেম করুন বা `datasetRoot` ঠিক করুন।
3. **শব্দ মেলান:** ডেটাসেটে এই ইংরেজি শব্দগুলো আছে কি না দেখুন এবং `sign.js`-এর `REASON_WORDS`, `DIGIT_EN` সেই অনুযায়ী বদলান: `zero…nine`, `call/phone`, `emergency`, `violence`, `child`, `salary`, `law` ইত্যাদি।
4. **CWASA টেস্ট:** ব্রাউজারে অবতার চলছে কি না দেখুন। না চললে `CWASAAvatar` কন্টেইনার `display:none` অবস্থায় init হচ্ছে কি না (`play()`-এ `avatarWrap` unhide করার পরে `CWASA.init()` কল করুন) এবং `playSiGMLURL` বনাম URL-ইনপুট+Play-বাটন পদ্ধতি পরীক্ষা করুন।
5. **ডিপ্লয়:** ব্যাকএন্ড `frontend/` স্ট্যাটিক সার্ভ করে, তাই `/bdsl/...` আপনাআপনি সার্ভ হবে। ৫০০০+ ফাইল Render-এ বড় হলে শুধু দরকারি ~২০–৩০টি সাইন (০–৯, call, কারণ-শব্দ) রাখুন।
6. **অফলাইন:** CWASA CDN-নির্ভর। দরকার হলে `allcsa.js` নিজের সার্ভারে হোস্ট করুন।
7. **মান যাচাই:** বধির ব্যবহারকারী বা BdSL দোভাষী দিয়ে সাইনগুলো দেখান।
